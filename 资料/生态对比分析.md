# DSH 插件市场生态对比分析

本项目的同类项目对比（2026-08 调研）。结论先行：本项目 = 「成熟市场的安装体验/安全」+「GitHub 实时全量数据」+「启动页入口」的杂交，是市面上唯一同时具备这三者的实现。

## 生态角色一览

| 项目 | ⭐ | 类型 | 定位 | 数据源 |
|---|---|---|---|---|
| [awesome-dsh-plugin/awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) | ~2000 | Python 站点/精选列表 | **数据层**（目录，非市场 UI） | 人工 PR 精选（~300 插件） |
| [dsh-market/dsh-market](https://github.com/dsh-market/dsh-market) | ~160 | TS 插件（npm 包 `dshmarket`） | harness 内市场 UI（官方推荐） | 精选目录 `plugins.json` |

## 关键结论

1. **数据源两条路线**：精选目录（dsh-market 路线，安全但慢）vs GitHub topic 实时（AwesomeHou 路线，全量但需自校验）。本项目选了后者，并用「dsh 清单校验 + 试装验证」补安全，是当前两者兼顾最接近的方案。
2. **agent 工具是 AwesomeHou 想清楚、dsh-market 没做的一个维度**：让模型自己用 `market_search/install/installed/update` 搜装插件，把市场从「UI 商店」升级为「模型可自我扩展的 harness」。
3. **启动页 onboarding 入口是本项目独有**：首次运行引导即出现插件商城，配合 localStorage 持久化「已看过」不重复弹出。
4. **dshfind 是站外网站**，不装进 harness，无法一键安装；它是学习社区，不是竞争者。

## 各项目可借鉴点（已采纳/未采纳）

- 已采纳 AwesomeHou：agent 工具四件套、内置/后装区分、市场自更新。
- 已采纳 dsh-market：后台进度、热挂载、一键重启、npm 优先安装。
- 未采纳（有意）：dsh-market 的精选目录白名单（改为 dsh 清单校验）、themes tab（可作后续里程碑）。
- 后续可选：主题 tab、日志导出、pnpm 缺失自动安装。
