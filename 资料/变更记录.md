11. **多 agent 全量修复轮**（2026-08-15，baseline `6916f5b`，对照宿主 deepseek-harness rc.5 源码审查后落地）：
    - **Windows 构建修复**（随 baseline）：`scripts/build.mjs` 直连 `typescript/bin/tsc` 与 `tsdown/dist/run.mjs` 真实入口，绕开 `.bin` 下的 POSIX sh 包装（Windows 上 node 执行必报 SyntaxError）。
    - **host 外科三修**（`6d06f82`）：① `scheduleRestart` 端口竞态——detached `node -e` 守护脚本轮询端口释放（net bind 试探，100ms×15s）后再拉起 dsh，旧进程先退，杜绝 EADDRINUSE 双死；② 热挂载/停用按插件 patch **行名**匹配 loader entry（`loaderNamesFor` helper，包名≠行名时旧逻辑永远验证失败）；③ searchCache 上限 200 逐出 + updatesCache 过期就地清理。
    - **client 两修**（`db86084`）：InstalledPanel 启停成功/失败 toast 反馈；翻页 scrollIntoView 滚回顶部。
    - **工具层重构（P0）**（`bf19784`）：4 个 `market_*` 工具 parameters 改 ParameterSchemaSpec DSL（本地 `compileParameterSpec` 编译为宿主 subset——宿主 schemaOf 原样透传 parameters，裸 DSL 会发给模型 API 残缺 schema）；`market_install`/`market_update` 有 `ctx.jobs` 时后台化（`{kind:'background',jobId}`，复用 startOp 基建，JobHooks 映射 JobOutcome，readOutput 增量游标），无 jobs 回退同步；与 UI 安装单飞互斥。
    - **实时 fiber 状态**（`94dd5e7`）：`listInstalled` 读 loader entries 投影 live（active/pending/loading/failed/unloading/stale），「已安装」面板徽章从文件态两态升级为运行时真态；`market_installed` 同步投影。
    - **审查修复轮**（`8e53108`）：单飞互斥下沉 `startOp` 咽喉点（封死 resolveInstallSpec/waitProxyReady 异步窗口，五调用点一次闭环）；readOutput 游标改累计坐标（200KB 截断后不再永久失效）；job cancel 限定本 op；disable 反馈按 `r.message` 选文案（停用立即生效不再误报"需重启"）+ 中性 toast 样式；补 fake jobs 全链路、marketJobHooks、liveLoaderStates FAILED 优先等测试盲区。
