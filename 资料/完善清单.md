# 四项完善清单（代码索引）

对比 AwesomeHou/dsh-plugin-marketplace 后落地的四项完善，提交 `7901d5f`（2026-08-15）。

## ① Agent 模型工具（模型可自搜自装）

**文件**：`src/host.ts` → `registerMarketTools()`；插件 `inject` 增加 `'tools'`。

| 工具 | 行为 | 复用 |
|---|---|---|
| `market_search(q, page, perPage)` | 搜 GitHub `topic:dsh-plugin`，JSON + 文本渲染 | `searchGitHub()` |
| `market_install(spec)` | 同步安装到 web profile，返回是否需重启 | `resolveInstallSpec()` 安全闸 + `dsh plugin add` |
| `market_installed()` | 内置/后装 + 版本 + 可更新 + 市场自更新 | `listInstalled()` + `checkSelfUpdate()` |
| `market_update(name)` | 更新单个已装插件 | `checkUpdates()` 目标解析 + `dsh plugin add` |

注册日志：启动时输出 `[dsh-market] registered model tools: market_search, market_install, market_installed, market_update`。

**顺带重构**：install 安全闸从 HTTP 路由内联代码抽成 `resolveInstallSpec(target, bin, profile)`，路由与工具共用（dsh 清单校验 → trial boot 试装验证 → npm 优先/codeload tarball + allowBuilds 放行）。

## ② 「已安装」独立标签页 + 内置/后装区分

- **Host**：`installed` 路由新增 `plugins[]` 字段——`kind: builtin|installed`、`enabled`、`version`、`latestVersion`、`updateAvailable`；builtin = 模板 bundles（只读），installed = profile dependencies（可管理）。实现：`listInstalled(profile)`。
- **Client**：`src/client/index.ts` → `InstalledPanel`，注册为 `settings.plugins.tab` id `installed`（order 6）。后装插件给启用/停用/更新/卸载；内置插件折叠只读。

## ③ 市场自更新检查

- **Host**：`checkSelfUpdate(profile)` —— 读自己 package.json 的 `repository` 字段（当前 `loker66fan/dsh-market-github`）→ GitHub contents API 取最新 version → 与已装版本比较。
- **Client**：「插件市场」与「已安装」两个标签页顶部均显示 `vX → vY · 更新` 横幅（`.mkts-selfupdate` 样式），点击走 `market_update` 流程。

## ④ 分页 perPage 可配置

- `src/client/index.ts`：模块级 `MARKET_PER_PAGE`（默认 50，clamp 1–100），`apply(ctx, config)` 读取插件 cordis 配置。
- `cordis.patch.yml`：`config: { perPage: 50 }` —— 部署时改这个数字即可。
